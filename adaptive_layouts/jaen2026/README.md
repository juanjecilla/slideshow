# Adaptive Layouts · Adaptarse o Morir

Edición en español de la charla para DevFest Jaén 2026 (GDG Jaén, online, 21 nov 2026): la que se dio. Es una
**Edition** del deck base (`../`, en inglés) publicada en <https://juanjecilla.github.io/slideshow/adaptive_layouts/jaen2026/>.
Juanje Cilla · hecha con [beatdeck](https://github.com/borjaperfra/beatdeck).

```bash
npm install
npm run dev          # http://127.0.0.1:5173/#1.1
npm run present      # build de producción, abierto en local (funciona sin conexión)
npm run verify       # cada paso comprobado → artifacts/verify/
```

Nota de procedencia: el contenido se escribió primero en español y el deck base en inglés (`../`) es la traducción;
por eso aquí el deck es el original y no una copia congelada. Las notas del ponente (`note` en `deck/scenes.ts`) están
en español. La documentación (investigación, decisiones, auditoría de contenido, checklist) está en `../docs/`.
