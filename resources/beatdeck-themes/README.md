# beatdeck themes

Reusable visual styles for [beatdeck](https://github.com/borjaperfra/beatdeck) decks. Each folder is independent of any talk: copy it into a deck project with its `install.sh`.

| Theme | Look | Use it for |
|---|---|---|
| [`poster/`](poster) | A series of posters: a full-bleed colour per scene, high-contrast serif, cream sheets for code and screenshots, a giant outlined scene number | Talks with a strong narrative and few, big ideas per scene; story-first, code-light decks |
