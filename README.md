## Setup

Each talk is a standalone Slidev project. To run locally:

```bash
cd <talk-folder>
npm install
npm run dev
```

## Deploy

Pushes to `main` trigger a GitHub Actions workflow that builds all talks and deploys to GitHub Pages automatically.
